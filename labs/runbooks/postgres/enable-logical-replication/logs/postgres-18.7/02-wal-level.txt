## A publication can be created at this level. Some versions answer with a warning.
CREATE PUBLICATION early_pub FOR TABLE orders;
WARNING:  "wal_level" is insufficient to publish logical changes
HINT:  Set "wal_level" to "logical" before creating subscriptions.
CREATE PUBLICATION
DROP PUBLICATION early_pub;
DROP PUBLICATION
