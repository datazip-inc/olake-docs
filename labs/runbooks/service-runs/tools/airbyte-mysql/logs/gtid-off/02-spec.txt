
## the CDC options in the connector's specification
method | title: None | default: 'CDC' | allowed: ['CDC'] | range: None to None
server_timezone | title: Configured server timezone for the MySQL source (Advanced) | default: None | allowed: None | range: None to None
invalid_cdc_cursor_position_behavior | title: Invalid CDC Position Behavior (Advanced) | default: 'Fail sync' | allowed: ['Fail sync', 'Re-sync data'] | range: None to None
initial_load_timeout_hours | title: Initial Load Timeout in Hours (Advanced) | default: 8 | allowed: None | range: 4 to 24

invalid_cdc_cursor_position_behavior: Determines whether Airbyte should fail or re-sync data in case of an stale/invalid cursor value in the mined logs. If 'Fail sync' is chosen, a user will have to manually reset the connection before being able to continue syncing data. If 'Re-sync data' is chosen, Airbyte will automatically trigger a refresh but could lead to higher cloud costs and data loss.
