<TLDR title='Key takeaways'>

No single ETL (extract, transform, load) tool wins for everyone, and the same goes for its cousin ELT (extract, load, transform). The tools differ on who runs them and what they bill for. Want a vendor to run everything and can live with a usage meter?

Pick Fivetran.

Have engineers and want code you can host yourself? Look at Airbyte or dlt.

Want database changes in Iceberg on your own storage? Look at OLake Go.

Already in one cloud? Use that cloud's tool, AWS Glue or Azure Data Factory.

Big company that needs governance? Informatica.

Prices below come from each vendor's own page (checked Nov 2026).

- **ETL and ELT are two orders of the same steps.** Most tools here can do either, so the label matters less than where your transforms run.
- **The price is a meter, not a number.** Run the same data through rows, events, credits, gigabytes or a flat fee. You'll get very different bills. Fivetran's pricing page prints no per-row rate, but its separate [Service Consumption Table](https://www.fivetran.com/legal/service-consumption-table) does (Standard starts at $495 per million MAR, checked Nov 2026). Matillion shows no dollar prices, and [Meltano Cloud](https://meltano.com/pricing) prices its plans in pounds.
- **Self-hosted tools have no licence fee.** Airbyte Core (under the Elastic License 2.0), dlt and OLake Go (open source, database changes into Apache Iceberg or Parquet) are free to run; you pay for servers and people.
- **Check that a tool is still actively sold.** [Talend Open Studio was retired](https://www.qlik.com/us/products/talend-open-studio) on 2024-01-31, and [Stitch](https://www.stitchdata.com/) steers new customers to Qlik Talend Cloud. Informatica and Rivery changed owners, and Fivetran merged with dbt Labs, since late 2024.

</TLDR>

## ETL vs ELT in plain words

ETL means copying data out of a source, changing its shape, and then putting it in a destination. ELT flips the order and changes the shape later, inside the destination. Microsoft's architecture guide says ELT differs from ETL solely in where the transformation takes place.

![ETL reshapes data on a separate engine before loading, while ELT loads raw data first and reshapes it later](/img/blog/2026/10/best-etl-tools-etl-vs-elt.webp)

AWS says teams can use both, with ETL for some sources and ELT for the rest. On this page, "ETL tools" means both kinds. Some tools below only copy data and leave the reshaping to a second tool such as dbt (data build tool, which runs SQL transforms in the destination).

## How we picked these tools

Each tool had to be still sold or maintained, move data between systems, and publish a way to try it. We checked each vendor's pricing and documentation pages in October 2026 and re-checked them in November 2026. Where a vendor hides a price, the table says "not published".

We did not run the other tools; this is a reading of vendor pages, not a lab test.

We left out Talend Open Studio (retired on 2024-01-31, per [Qlik](https://www.qlik.com/us/products/talend-open-studio)) and tools that only schedule jobs, such as Apache Airflow. The groups below aren't a ranking.

## The 15 Best ETL Tools in 2026

### Managed services you pay a vendor to run

#### 1. Fivetran: for hands-off connectors

**At a glance**

- Billed by: monthly active rows (MAR), meaning rows that changed in a month, counted per connection
- Price: the Free plan covers up to 500,000 MAR; paid rates are in its Service Consumption Table, not on the pricing page (Standard from $495 per million MAR plus a $5 base per connection, Enterprise from $661.67, Business Critical from $1,061.67, list price per connection) ([Service Consumption Table](https://www.fivetran.com/legal/service-consumption-table), checked Nov 2026)
- Status: active, and merged with dbt Labs on 2026-06-01, according to [Fivetran's press release](https://www.fivetran.com/press/fivetran-dbt-labs-complete-merger-to-create-the-data-infrastructure-for-trusted-ai-agents)

[Fivetran's pricing page](https://www.fivetran.com/pricing) lists four plans: Free, Standard, Enterprise and Business Critical. It runs the connectors for you and loads into a warehouse or lake. It also writes Iceberg tables to cloud storage through its Managed Data Lake Service, and its [Managed Data Lake Service docs](https://fivetran.com/docs/managed-data-lake-service) say position deletes are not supported (checked Nov 2026).

**Pick it if** you want a vendor to own connector upkeep and you'd rather pay a meter than hire an engineer.

**Look elsewhere if** your volume is high and changes constantly, because every connection has its own cost curve. Its Oracle and High-Volume Agent connectors count as enterprise database connectors, which its [pricing page](https://www.fivetran.com/pricing) lists from the Enterprise plan up (checked Nov 2026).

**Ask Fivetran before you sign** for a monthly active rows estimate on your busiest table, since the pricing page prints no per-row rate.

#### 2. Hevo: for small teams that want a flat price per event quota

**At a glance**

- Billed by: events, where each record inserted, updated or deleted counts as one
- Price: Starter is $299 monthly or $265 billed yearly for the first 5M-event step; Professional starts at $849 monthly or $750 yearly; Hevo has a 14-day free trial ([Hevo pricing](https://hevodata.com/pricing/pipeline/), checked Nov 2026)
- Status: active, with numbered releases through August 2026

Hevo's pricing page lists a 14-day trial with no card. Its [docs](https://docs.hevodata.com/pipelines/working-with-pipelines/log-based-pipelines/) describe log-based capture for MySQL, PostgreSQL, MongoDB, SQL Server and Oracle. Its pricing page lists streaming pipelines on Professional and Enterprise, while Starter syncs hourly.

**Pick it if** you're a small team with common SaaS (software as a service) sources and you'd like to try it on a 14-day free trial first.

**Look elsewhere if** your tables change a lot, since a row updated five times counts as five events. Its Iceberg destination, [Snowflake Iceberg](https://docs.hevodata.com/edge/destinations/snowflake-iceberg/), is in early access (checked Nov 2026).

#### 3. Stitch: for simple row-based replication

**At a glance**

- Billed by: replicated rows per month, including rows from nested data
- Price: Standard starts at $100 a month for 5M rows; Advanced is $1,500 a month billed yearly for 100M rows; Premium is $3,000 a month billed yearly for 1B rows ([Stitch pricing](https://www.stitchdata.com/pricing/), checked Nov 2026)
- Status: active, but part of Qlik

Stitch's pricing page shows no free plan, only a 14-day trial. On its [home page](https://www.stitchdata.com/), Stitch says "Stitch is now part of Qlik" and tells new users who want a warehouse or lake to try Qlik Talend Cloud. Its [changelog](https://www.stitchdata.com/docs/changelog/) shows updates dated November 2026, so we don't call it shut down.

**Pick it if** you just want a simple, scheduled copy of SaaS and database tables and your row counts are modest.

**Look elsewhere if** you need Iceberg output or a free plan: its [destinations list](https://www.stitchdata.com/docs/destinations) shows no Iceberg option, and its pricing page offers only a 14-day trial (checked Nov 2026). Ask Qlik about Stitch's plans before you commit. For a head-to-head, see Airbyte vs Stitch.

#### 4. Integrate.io: for predictable flat pricing

**At a glance**

- Billed by: a flat fee, with "unlimited" data volume, pipelines and connectors
- Price: Core is $1,999 a month, shown as "/mo"; the page does not say whether it is billed monthly or yearly ([Integrate.io pricing](https://www.integrate.io/pricing/), checked Nov 2026)
- Status: active

Integrate.io's pricing page lists Core with a 60-second pipeline frequency and 30-day onboarding. A second card, "Design Your Plan", covers security, access control and HIPAA (a US health privacy law) readiness at a price that is not published. You can try it for 14 days.

**Pick it if** you move large, steady volumes and want the flat fee its pricing page describes, which does not depend on row counts.

**Look elsewhere if** your volume is small, since $1,999 a month ($23,988 over 12 months) is a lot next to free plans. Also, its 60-second minimum is near-real-time, not streaming.

#### 5. Skyvia: for no-code work and small jobs

**At a glance**

- Billed by: records created, updated or deleted in the target
- Price: Free is $0 for 10,000 records a month; Basic is $99 monthly or $79 billed yearly; Standard is $199 monthly or $159 yearly ([Skyvia pricing](https://skyvia.com/pricing), checked Nov 2026)
- Status: active, made by Devart

Skyvia's pricing page shows how many records each paid plan includes only through a selector, so we don't quote those counts. Free plans run daily, with two scheduled integrations and a 30-day schedule expiry. Its [replication docs](https://docs.skyvia.com/data-integration/replication/configuring-replication-integration.html) say log-based mode is available only for SQL Server (checked Nov 2026).

**Pick it if** you want a no-code tool for spreadsheets, SaaS apps and small databases, and you'd rather click than code.

**Look elsewhere if** you need syncs more often than hourly on a low tier, since its pricing page puts once-a-minute schedules on the Professional plan. Also, its [connectors list](https://skyvia.com/connectors/) shows no Iceberg connector (checked Nov 2026).

#### 6. Rivery (Boomi Data Integration): for credit-based ELT with a trial

**At a glance**

- Billed by: credits, called BDU (also called RPU); database sources by bytes moved, most API sources by pipeline run
- Price: $0.9 per credit pay-as-you-go on the Base edition, with one environment and two users ([Rivery pricing](https://rivery.io/pricing/), checked Nov 2026)
- Status: active, bought by Boomi in December 2024 and renamed Boomi Data Integration, [per Boomi](https://boomi.com/rivery-is-now-boomi-data-integration/)

Rivery's pricing page offers a free trial of 14 days or 1,000 credits, whichever ends first, so "Free" here is a trial, not a lasting plan. Its docs describe log-based capture for MySQL (binary log), [Oracle (LogMiner)](https://help.boomi.com/docs/Atomsphere/Data_Integration/Sources/Databases/Oracle/RiverConfigurations/OracleCDC/oracle-change-data-capture-overview) and SQL Server. Its pricing page puts Oracle capture on the Enterprise plan only (checked Nov 2026).

**Pick it if** your team already uses Boomi, or you like having ELT and job scheduling under one roof.

**Look elsewhere if** you want Apache Iceberg output. Boomi's [targets list](https://help.boomi.com/docs/Atomsphere/Data_Integration/Targets/targets-overview) shows no Iceberg target (checked Nov 2026).

#### 7. Estuary: for real-time capture with a free tier

**At a glance**

- Billed by: $0.50 per GB moved, plus connector instances
- Price: the first 6 connector instances cost $100 a month each, then $50 each; Free is 10 GB a month and 2 instances ([Estuary pricing](https://estuary.dev/pricing/), checked Nov 2026)
- Status: active, with Flow releases through August 2026

Estuary's pricing page counts each source (a capture) and each destination (a materialization) as one instance. That means one source feeding one destination is two instances, not one. Its docs list log-based capture for PostgreSQL, MySQL, MariaDB, SQL Server, Oracle and DynamoDB.

**Pick it if** you want the real-time delivery and log-based change capture its pricing page lists (we did not measure either) and a free tier without a sales call.

**Look elsewhere if** you fan one source out to many destinations, because each one adds $50 to $100 a month. Its [Iceberg connector](https://docs.estuary.dev/reference/Connectors/materialization-connectors/apache-iceberg/) needs a catalog that uses the REST (web API) style, an S3 staging bucket, and Amazon's Elastic MapReduce (EMR) Serverless Spark service. Its runtime's [licence](https://github.com/estuary/flow/blob/master/LICENSE-BSL) is the Business Source License 1.1, not an open-source licence (checked Nov 2026).

### Tools you host yourself (and babysit)

#### 8. Airbyte: for a large self-hostable connector library

**At a glance**

- Billed by: credits on Cloud; nothing for Core
- Price: Cloud Standard is $20 a month with 5 credits and $5 per extra credit since 2026-09-21; Plus starts at $189 for 40 credits ([Airbyte pricing](https://airbyte.com/pricing) and [release notes](https://docs.airbyte.com/release_notes/cloud), checked Nov 2026)
- Status: active; [Airbyte 2.0](https://docs.airbyte.com/release_notes/self-managed/v-2.0) shipped on 2025-10-14

Airbyte's Cloud release notes dated 2026-09-15 raised the Standard base price from $10 to $20 and the extra-credit price from $2.50 to $5.00. Both doubled. Airbyte Core is free to self-host under the Elastic License 2.0 (ELv2), which, per its [licence FAQ](https://docs.airbyte.com/community/licenses/license-faq), stops you from selling it as a hosted service.

It writes Iceberg through its S3 Data Lake destination.

**Pick it if** you have engineers, want a large connector catalog you can self-host, and like knowing a cloud option is there later.

**Look elsewhere if** you need streaming. Its [CDC docs](https://docs.airbyte.com/platform/understanding-airbyte/cdc) say CDC (change data capture, reading a database's change log) runs as scheduled syncs. Its Pro and Flex prices are not published, and its docs say [Self-Managed Enterprise](https://docs.airbyte.com/platform/enterprise-setup) is no longer sold (checked Nov 2026).

#### 9. Meltano: for code-first Singer pipelines

**At a glance**

- Billed by: nothing for the [MIT-licensed](https://github.com/meltano/meltano/blob/main/LICENSE) core; Meltano Cloud plans use compute hours
- Price: Meltano Cloud Starter is £12,000 a year with 200 compute hours a month, then £2.00 an hour; it shows no dollar prices ([Meltano pricing](https://meltano.com/pricing), checked Nov 2026)
- Status: active; Matatika acquired the Meltano open-source project, per [Meltano's blog](https://meltano.com/blog/looking-for-arch) of March 1, 2026

[Meltano's pricing page](https://meltano.com/pricing) says the open-source version is "not really suited for production teams unless you have a dedicated DevOps crew". It runs Singer connectors (called taps and targets), and many were written by the community. Whether you get log-based capture depends on which tap variant you pick.

**Pick it if** your team likes pipelines kept as code in version control and doesn't mind choosing between community connectors.

**Look elsewhere if** you need Iceberg beyond Amazon S3 Tables. For Iceberg, its Hub lists the community-supported [target-s3tables](https://hub.meltano.com/loaders/target-s3tables/) loader, built for S3 Tables (checked Nov 2026).

#### 10. dlt: for Python teams that write their own pipelines

**At a glance**

- Billed by: nothing for the [Apache 2.0](https://github.com/dlt-hub/dlt/blob/devel/LICENSE.txt) library
- Price: the dltHub platform is pay-as-you-go at $10 per runtime hour with no minimum spend, or an Annual Commitment at a custom price with a 12-month minimum term ([dltHub pricing](https://dlthub.com/pricing), checked Nov 2026)
- Status: active, with frequent releases through August 2026

The dlt library is free and open source, and dltHub's pricing page covers only the paid platform. The library runs anywhere Python runs, according to its docs. Those docs say it writes Iceberg tables through the filesystem destination and PyIceberg, and that you supply the catalog.

**Pick it if** your team writes Python and likes the idea of a pipeline being a small piece of code.

**Look elsewhere if** you want point-and-click setup or database change capture across many engines. In the open-source library, its [sources overview](https://dlthub.com/docs/dlt-ecosystem/verified-sources/) names Postgres replication as the only built-in change data capture source (checked Nov 2026).

#### 11. Apache NiFi: for drag-and-drop dataflows you host

**At a glance**

- Billed by: nothing; you pay for your own servers and staff
- Price: free under the [Apache 2.0 licence](https://github.com/apache/nifi/blob/main/LICENSE)
- Status: active; NiFi's [download page](https://nifi.apache.org/download/) says version 1 lost support on 2024-12-08

Apache NiFi describes itself as a system to process and distribute data, with a browser interface, data provenance tracking and guaranteed delivery. It has a [PutIcebergRecord](https://nifi.apache.org/components/org.apache.nifi.processors.iceberg.PutIcebergRecord/) processor that stores records in an Iceberg table through a REST catalog. The processor page does not say how it handles updates or deletes (checked Nov 2026).

**Pick it if** you want a visual flow designer for routing files and messages, and you want to control every piece of it.

**Look elsewhere if** you want a ready catalog of SaaS connectors. It has a [CaptureChangeMySQL](https://nifi.apache.org/components/org.apache.nifi.cdc.mysql.processors.CaptureChangeMySQL/) processor, but we didn't check other databases, so confirm yours first.

### Cloud platforms from the Big Three

#### 12. AWS Glue: for teams already on AWS

**At a glance**

- Billed by: DPU-hours (data processing units, the compute AWS bills for), by the second with a 1-minute minimum
- Price: $0.44 per DPU-hour for ETL jobs, and $0.308 on Glue 6.0 and above, in US East (Ohio) ([AWS Glue pricing](https://aws.amazon.com/glue/pricing/) and its price list, checked Nov 2026)
- Status: active; Glue 6.0 shipped in August 2026

AWS Glue's pricing page shows no free ETL tier. The first 1 million Data Catalog objects and requests each month are free, though. Glue reads and writes Iceberg tables and runs on Apache Spark.

**Pick it if** your data and team are already inside AWS and someone can write Spark jobs.

**Look elsewhere if** you want simple point-and-click replication or you are not on AWS. A job created without a version defaults to Glue 6.0 at the lower rate, per the [AWS Glue docs](https://docs.aws.amazon.com/glue/latest/dg/add-job.html), but a job pinned to an older version still bills $0.44 (checked Nov 2026). Read AWS Glue pricing explained for a worked bill.

#### 13. Azure Data Factory: for teams already on Azure

**At a glance**

- Billed by: several meters, including activity runs, data movement and data flow compute
- Price (US East, pay as you go): $1.00 per 1,000 activity runs, $0.25 per DIU-hour for data movement (a DIU is a data integration unit), and $0.274 per vCore-hour for General Purpose data flows ([ADF pricing](https://azure.microsoft.com/en-us/pricing/details/data-factory/data-pipeline/), checked Nov 2026)
- Status: active, but Microsoft's [own docs](https://learn.microsoft.com/en-us/azure/data-factory/introduction) point new users to Fabric Data Factory

Azure's pricing page loads its rates with scripts, so we read them from Microsoft's retail price feed and checked them against a live render. We found no free tier published, either. Microsoft's [comparison page](https://learn.microsoft.com/en-us/fabric/data-factory/compare-fabric-data-factory-and-azure-data-factory) says new Fabric Data Factory features are not backported to Azure Data Factory.

**Pick it if** you're on Azure and want a visual designer with plenty of connectors.

**Look elsewhere if** you want database change capture for open-source databases. Its [native capture](https://learn.microsoft.com/en-us/azure/data-factory/concepts-change-data-capture) covers connectors such as SQL Server, Azure SQL and Cosmos DB, and its [Iceberg format](https://learn.microsoft.com/en-us/azure/data-factory/format-iceberg) is supported only on Azure Data Lake Storage Gen2 (checked Nov 2026). See Azure Data Factory pricing explained.

### Warehouse and Enterprise Platforms

#### 14. Matillion: for transforms that run inside your warehouse

**At a glance**

- Billed by: credits for pipeline run time (1 credit per task hour for orchestration and 3 for transformation, per its [credit terms](https://www.matillion.com/legal/credit-consumption-terms)) plus extra developer users
- Price: Developer, Teams and Scale editions with no dollar prices published
- Status: active; its [credit terms](https://www.matillion.com/legal/credit-consumption-terms) call Maia Foundation the former Data Productivity Cloud

[Matillion's pricing page](https://www.matillion.com/pricing) shows credits but no price per credit, and its credit terms say the overage rate is listed on the order form, so you'll have to ask. The pricing page puts streaming change capture on the Scale edition, and its [streaming docs](https://docs.maia.ai/docs/streaming/streaming-pipelines) list five relational sources. Those docs list Amazon S3, Azure Blob Storage, Google Cloud Storage and Snowflake as streaming destinations, with no Iceberg option (checked Nov 2026).

**Pick it if** your destination is Snowflake, Databricks, Redshift or BigQuery and you want transforms pushed down into it.

**Look elsewhere if** you need a price before you talk to sales, since none is published.

#### 15. Informatica: for governed enterprise integration

**At a glance**

- Billed by: Informatica Processing Units (IPU), which each service uses up every month
- Price: AWS Marketplace lists one bundle of 120 IPUs a month at $131,760 for 12 months; Informatica's own site shows no dollar price per IPU ([AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-vetdnosd4u6oe), checked Nov 2026)
- Status: active, and owned by Salesforce since 2025-11-18, per [Salesforce](https://www.salesforce.com/news/press-releases/2025/11/18/salesforce-completes-acquisition-of-informatica/)

[Informatica's free page](https://www.informatica.com/free-data-integration.html) offers Cloud Data Integration Free with up to 20M rows or 10 compute hours a month. A document called the Cloud and Product Description Schedule publishes processing-unit rates per service in tiers. Its database replication docs list sources such as Oracle, SQL Server and Db2, and its Open Table Connector reads and writes Iceberg tables.

**Pick it if** you're a large company that needs governance, many older source systems such as Db2 and SAP (a business software maker), and a vendor contract.

**Look elsewhere if** you need a firm price without a sales conversation. Treat the marketplace list price as a reference point, not a quote.

## How to choose an ETL tool

1. **Who will run it?** If nobody can own servers, shortlist the managed services. Got engineers? Add the tools you host yourself.
2. **Where does the data land?** Warehouse-only tools are fine for Snowflake or BigQuery. If you want open table files such as Iceberg, check each tool's docs. The destination lists of [Matillion's streaming pipelines](https://docs.maia.ai/docs/streaming/streaming-pipelines), [Stitch](https://www.stitchdata.com/docs/destinations), [Skyvia](https://skyvia.com/connectors/) and [Rivery](https://help.boomi.com/docs/Atomsphere/Data_Integration/Targets/targets-overview) show no Iceberg option (checked Nov 2026).
3. **What will the meter count?** Estimate rows changed, events or gigabytes for one busy month, then price that on each vendor's page. A table that updates the same rows all day is cheap on a flat fee and costly on a row meter.
4. **How fresh must it be?** Hourly is enough for most reports. If you need changes within minutes, read each tool's change-capture limits first.
5. **What if the vendor changes?** Fivetran merged with dbt Labs, Salesforce bought Informatica, Boomi bought Rivery. Airbyte doubled its Standard base price in September 2026.

## One line about OLake Go

OLake Go copies databases, Kafka and S3 into Apache Iceberg or Parquet on storage you control, with full load and then change capture for Postgres, MySQL and MariaDB, MongoDB and SQL Server (see the [OLake Go docs](/docs/)). It is open source and installs with Docker or Helm ([install docs](/docs/install/docker-cli/)). Output is Iceberg or Parquet. On the way it can flatten nested JSON and filter rows ([stream properties](/docs/understanding/terminologies/olake/)), but it has no modelling or SQL transform step, so a warehouse load or heavier in-flight transforms call for one of the tools above.

Several warehouses and query engines can read the Iceberg tables it writes (see [engine compatibility](/docs/understanding/compatibility-engines/)). Pick OLake Go when the goal is database changes in Iceberg on storage you run. For wider lists, see [best data integration tools](/compare/best-data-integration-tools/) and [best data ingestion tools](/compare/best-data-ingestion-tools/).
