# OLake Go (v1.1.0)
Oct 25, 2026 – Oct 26, 2026

## 🎯 What's New

### Destinations

1. **Added Azure Blob Storage Support for Parquet -** <br/> Added support for Azure Blob Storage (ADLS Gen2 via Blob API) as a Parquet destination.

## 🔧 Bug Fixes & Stability

1. **Fixed Parquet Stream Configuration Validation -** <br/> Updated stream difference detection and sync validation to ignore `append_mode`, `update_type`, and `dedup_keys` for Parquet destinations, since these settings do not affect Parquet behavior.
