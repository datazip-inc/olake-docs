# OLake Go (v1.1.0 - v1.1.2)
Oct 25, 2026 – Nov 10, 2026

## 🎯 What's New

### Sources

1. **Added MySQL CDC Support Across Server Switchovers -** <br/> Added support for resuming MySQL CDC from saved GTID checkpoints after a replica promotion or server switchover, without requiring a new backfill. Existing pipelines can continue using their saved checkpoints, see the [MySQL migration guide](/docs/connectors/mysql/#migrate-an-existing-job-to-gtid) for details.

2. **Added Certificate File Upload Support -** <br/> Added support for uploading certificate files directly for MySQL, MongoDB, Kafka, and PostgreSQL connections, eliminating the need to copy and paste certificate contents manually.

### Destinations

1. **Added Azure Blob Storage Support for Parquet -** <br/> Added support for Azure Blob Storage (ADLS Gen2 via Blob API) as a Parquet destination.

2. **Added Azure Managed Identity Authentication -** <br/> Added managed identity authentication for Azure Blob Storage (Parquet destination), supporting Microsoft Entra ID, Azure VM managed identity, and AKS Workload Identity. For details, see the [Azure Managed Identity Authentication](/docs/writers/parquet/config/?azure-auth-type=managed-identity#configuration-1) documentation.

### Catalogs

1. **Added Catalog-Aware Delete Format Selection -** <br/> Updated discover to filter available delete formats based on destination catalog capabilities and target query engine compatibility, preventing unsupported delete formats from being selected.

## 🔧 Bug Fixes & Stability

1. **Fixed Parquet Stream Configuration Validation -** <br/> Updated stream difference detection and sync validation to ignore `append_mode`, `update_type`, and `dedup_keys` for Parquet destinations, since these settings do not affect Parquet behavior.

2. **Fixed Guava Security Vulnerability -** <br/> Upgraded Guava to version 33.7.2-android in the Iceberg writer to address CVE-2026-102554 and resolve the associated security vulnerability.

3. **Fixed MongoDB Read Preference Configuration -** <br/> Fixed an issue where `read_preference` was ignored for MongoDB Atlas SRV connections without an explicitly configured replica set, ensuring the configured read preference is applied correctly.

4. **Fixed Kafka Upsert Delete Handling -** <br/> Fixed Kafka upsert mode to respect the configured `update_type`, ensuring positional or deletion vector deletes are used according to the target catalog's capabilities.
