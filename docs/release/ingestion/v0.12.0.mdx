# OLake Go (v0.12.0 - v0.12.2)
Oct 7, 2026 – Oct 19, 2026

## 🎯 What's New

### Sources

1. **Kafka upsert mode -** <br/> Added support for Kafka upserts using Iceberg positional deletes, allowing records to be updated based on configured `dedup_keys`, with optional tombstone-based deletes when using `_kafka_key`. For details, see the [Kafka upsert behavior documentation](https://olake.io/docs/connectors/kafka/#upsert-behavior).

2. **CDC prerequisite checks in test connection -** <br/> Added CDC prerequisite checks to test connection results, reporting required server settings and permissions, current values, and recommended values. Required checks are enforced for explicitly configured CDC connections.

3. **MySQL binary column support -** <br/> Added support for syncing `BINARY`, `VARBINARY`, and `BLOB` columns as binary data, preserving non-UTF-8 bytes. Added state-version gating to maintain backward compatibility with existing syncs.

### Platform Features

1. **S3-backed configuration storage -** <br/> Added support for using S3 as shared storage for CLI configuration and sync files. Docker Compose deployments can use S3 instead of local storage, while UI and Helm/Kubernetes deployments can use S3 instead of requiring NFS.

2. **Removed approval requirement for master integration tests -** <br/> Updated the CI workflow to skip environment approval for integration tests on PRs targeting master, while retaining approval requirements for other pull requests.

3. **Automated performance testing for master PRs -** <br/> Updated the performance test workflow to run automatically on pull requests targeting master, support manual triggers, and include additional build, driver, and test files in path-based filtering.

## 🔧 Bug Fixes & Stability

1. **Fixed retry count initialization -** <br/> Fixed an off-by-one error that increased user-configured retry counts by one. Retry count defaults are now consistently initialized during configuration validation across all drivers.

2. **Updated Go security dependencies -** <br/> Updated Go to 1.26.9 and `golang.org/x/net` to v0.60.0 to address security vulnerabilities and restore the Go Security CI checks.

3. **Fixed append mode defaults for S3 and append-only drivers -** <br/> Fixed an issue where S3 streams did not default to `append_mode: true`. Centralized append-only driver detection to ensure consistent behavior across supported drivers.

4. **Fixed operation type handling in Iceberg writers -** <br/> Fixed an issue where insert operations were incorrectly relabeled as creates for non-append streams using positional or deletion vector modes. The relabeling now applies only when ResolveUpsertOp() is enabled.

5. **Fixed Iceberg catalog name validation -** <br/> Updated Iceberg catalog name validation to allow numbers and underscores, aligning UI validation with CLI and backend behavior.

6. **Fixed first-sync LSN mismatch under concurrent writes -** <br/> Fixed an issue where PostgreSQL CDC's first sync could fail due to a mismatch between the saved LSN and the replication slot position under concurrent write load. The slot is now confirmed before the initial state is saved.

7. **Fixed MariaDB CDC binlog compatibility -** <br/> Fixed an issue where MariaDB CDC could repeatedly fail on GTID events because the binlog syncer used the MySQL flavor. OLake now detects the server flavor and uses the appropriate binlog configuration for MySQL or MariaDB.

8. **Fixed CTID chunk sizing for TOAST-heavy tables -** <br/> Fixed PostgreSQL CTID chunk sizing to account for TOAST data, preventing oversized chunks on large tables and allowing long-running syncs to make incremental progress.

9. **Improved Kafka upsert error message -** <br/> Updated Kafka upsert validation errors to identify the configured deduplication keys when all selected keys are missing or null.
