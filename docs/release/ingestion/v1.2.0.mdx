# OLake Go (v1.2.0 - v1.2.2)
Nov 11, 2026 – Nov 20, 2026

## 🎯 What's New

### Sources

1. **Added PostgreSQL TOAST Value Preservation -** <br/> Added the `preserve_toast_values` option for PostgreSQL CDC to preserve unchanged TOAST column values during updates by recovering them from previously synced data or the destination Iceberg table. Disabled by default; enable it when configuring the source. For configuration details, see the [PostgreSQL TOAST columns](/docs/connectors/postgres/#toast-columns-preserve) documentation.

2. **Improved MongoDB CDC Resume Token Support -** <br/> Added support for preserving complete MongoDB resume tokens, including _typeBits, ensuring reliable recovery and resumption of change streams.
    :::important compatibility
    Downgrade to any earlier version is not supported after running MongoDB CDC on **v1.2.2**, as the state and destination metadata use a new format.
    :::

### Destinations

1. **Added Decimal Type Support -** <br/> Added native `decimal(p,s)` support in Iceberg and Parquet destinations, preserving precision and scale without converting supported decimal values to double. Added decimal type mapping for PostgreSQL, MySQL, SQL Server, Oracle, Db2, and S3 Parquet sources.

## 🔧 Bug Fixes & Stability

1. **Upgraded Go to 1.26.11 -** <br/> Upgraded Go from 1.26.10 to 1.26.11 to address security vulnerability GO-2026-6859 (CVE-2026-97054) in the `net/http` package.

2. **Fixed MongoDB Backfill for Mixed _id Types -** <br/> Fixed backfill failures and data loss when MongoDB collections contain multiple _id data types. Mixed-type collections now sync all documents correctly, including when resuming from existing state.
