# OLake Go (v0.11.0)
Sept 11, 2026 – Sept 26, 2026

## 🎯 What's New

### Catalogs

1. **Snowflake Horizon Catalog support -** <br/> Added support for Snowflake Horizon Catalog as an Iceberg REST Catalog, with authentication options for Programmatic Access Token (PAT), Key Pair Authentication, and External OAuth. See [Horizon Catalog setup](/docs/writers/iceberg/catalog/rest/?rest-catalog=horizon) for detailed configuration options.

### Destinations

1. **Iceberg v3 deletion vector support -** <br/> Added support for Iceberg v3 deletion vectors as a delete mode, alongside the existing equality and positional delete modes. See [Upsert Ingestion Mode](/docs/understanding/terminologies/olake/#upsert) for delete format options and their respective behaviors.

### Platform Features

1. **Improved telemetry and error classification -** <br/> Added `source_type` to completed sync telemetry and improved error classification for configuration and CDC validation failures, providing more useful context when diagnosing failed runs.

## 🔧 Bug Fixes & Stability

1. **Fixed case-sensitive PostgreSQL publication validation -** <br/> Fixed PostgreSQL CDC publication validation to correctly handle case-sensitive schema and table names.

2. **Updated MinIO image sources -** <br/> Updated MinIO and `mc` image references to use the OLake-maintained mirror, ensuring Iceberg local-test and MinIO-based example stacks continue to work.

3. **Fixed local Iceberg and S3 test stack management -** <br/> Updated the local test Compose setup so the destination stack manages its own MinIO instance, preventing S3 teardown from unintentionally removing Iceberg services and cached data.
