# OLake Go (v1.0.0 - v1.0.2)
Oct 22, 2026 – Oct 26, 2026

## 🎯 What's New

### Sync & CLI

1. **Introduced Streams V2 -** <br/> Split stream configuration into `available_streams.json` and `selected_streams.json` to separate discovered metadata from user-selected settings, while retaining streams.json for backward compatibility. For details, see the [Streams configuration documentation](/docs/install/docker-cli/#streams-config).

    :::warning 
    The legacy streams format is deprecated and will be removed in a future release. Migrate to Streams V2.
    :::

## 🔧 Bug Fixes & Stability

1. **Fixed MongoDB Timestamp Chunking Configuration -** <br/> Made the timestamp chunking strategy case-insensitive to ensure consistent behavior regardless of capitalization.

2. **Fixed Metadata State Updates for Empty Syncs -** <br/> Updated Iceberg and S3 Parquet destinations to persist 2PC metadata state on every CDC or incremental sync, even when no records are written, keeping metadata aligned with the sync state.
