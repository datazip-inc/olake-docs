# Compatibility to Iceberg Catalogs

OLake Go supports multiple Iceberg catalog implementations, including [REST catalog](/docs/writers/iceberg/catalog/rest/), [Hive Metastore](/docs/writers/iceberg/catalog/hive/), and [JDBC Catalog](/docs/writers/iceberg/catalog/jdbc/), letting you choose the one that best fits your environment. The table below shows the supported catalogs at a glance, with links to their setup guides.

OLake Go narrows the delete formats by catalog from v1.1.2 ([release notes](/docs/release/ingestion/v1.1.0)). Snowflake does not support equality deletes from external engines, Unity Catalog rejects equality delete files, and Nessie does not support Iceberg v3, which deletion vectors need. Within what the catalog allows, OLake Go picks the format from the job's [target query engines](/docs/understanding/compatibility-engines/#how-olake-go-picks-the-delete-format).
