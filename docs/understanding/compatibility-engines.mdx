## Important Notes

- **Presto** → REST catalog supported from **v0.288+**; Glue requires the AWS SDK fat-jar. Presto has no JDBC catalog: its Iceberg catalog types are Hive, Nessie, REST and Hadoop ([Presto Iceberg connector docs](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/iceberg.rst), checked Nov 2026).
- **Apache Hive v4.2.0** → Glue requires adding the AWS bundle.
- **Impala** → Reliable support for Hive Metastore; limited REST catalog support (read only).
- **ClickHouse** → Full read support; experimental Iceberg write support introduced in v25.7+. S3 Tables is a `DataLakeCatalog` catalog type from 26.8 ([ClickHouse changelog](https://clickhouse.com/docs/whats-new/changelog), checked Nov 2026).
- **Snowflake** → Reads externally managed Iceberg tables through catalog integrations, and can write to tables in a remote Iceberg REST catalog ([Snowflake Iceberg tables](https://docs.snowflake.com/en/user-guide/tables-iceberg), checked Nov 2026).
- **Azure Synapse Analytics** → Iceberg support via Spark pools requires manual runtime configuration. Synapse's current runtime is Spark 3.5 ([Synapse runtimes](https://learn.microsoft.com/en-us/azure/synapse-analytics/spark/apache-spark-version-support), checked Nov 2026).
- **Athena and Redshift (⚠️)** → Unity Catalog and Polaris tables are reachable only through AWS Glue catalog federation, and federated tables are read-only. AWS documents the Snowflake and Databricks sources in detail and asks you to validate Polaris first ([AWS catalog federation guide](https://docs.aws.amazon.com/prescriptive-guidance/latest/apache-iceberg-on-aws/catalog-federation-for-apache-iceberg-tables.html), checked Nov 2026). OLake Go upserts Unity tables with deletion vectors only, so Athena, which reads no Iceberg v3 tables, sees them only from append-only jobs.
- **BigQuery (⚠️)** → AWS Glue and Unity Catalog tables are read through a Lakehouse federated catalog, generally available since 2 Nov 2026 ([Lakehouse release notes](https://docs.cloud.google.com/lakehouse/docs/release-notes), checked Nov 2026). On Unity, OLake Go upserts with deletion vectors only, which BigQuery reads only in Preview.
- **StarRocks and Apache Doris (⚠️)** → These cells go through the generic REST catalog and are not documented by the vendor. StarRocks documents OAuth2, JSON Web Token (JWT) and SigV4 for REST catalogs, not the Google authentication BigLake needs ([StarRocks Iceberg catalog](https://docs.starrocks.io/docs/data_source/catalog/iceberg/), checked Nov 2026).
- **Apache Doris JDBC (⚠️)** → The Iceberg JDBC catalog is an experimental feature from Doris 4.1.0 ([Doris Iceberg catalog](https://doris.apache.org/docs/lakehouse/catalogs/iceberg-catalog), checked Nov 2026).

## Delete Format Support by Query Engine

OLake Go writes Iceberg tables using one of three row-level delete formats: **equality deletes**, **positional deletes**, or **deletion vectors**. Not all query engines support all three formats, so check the table below to see which query engines support which delete file format.

| Query Engine                                 | Equality Deletes | Positional Deletes | Deletion Vectors |
|----------------------------------------------|------------------|--------------------|------------------|
| Amazon Athena                                | ✅ | ✅ | ❌ |
| Apache Spark (3.5+; Iceberg 1.8+ for DV)     | ✅ | ✅ | ✅ |
| Apache Flink (1.20+; Iceberg 1.8+ for DV)    | ✅ | ✅ | ✅ |
| Trino (480+)                                 | ✅ | ✅ | ⚠️ |
| Starburst Enterprise                         | ✅ | ✅ | ⚠️ |
| Presto (v0.288+)                             | ⚠️ | ✅ | ❌ |
| Apache Hive (4.2+)                           | ✅ | ✅ | ⚠️ |
| Apache Impala (4.5)                          | ⚠️ | ✅ | ❌ |
| Dremio (v25/26)                              | ⚠️ | ✅ | ⚠️ |
| DuckDB (1.5.3+)                              | ⚠️ | ✅ | ✅ |
| ClickHouse (25.8+; DV 26.10+)                | ✅ | ✅ | ⚠️ |

| Azure Synapse Analytics (Iceberg 1.8+ for DV) | ✅ | ✅ | ✅ |

:::note[Dremio delete format caveats]
- **Equality deletes:** Dremio does not support reading **global equality deletes** on Iceberg v2 tables when the delete file's partition spec is **unpartitioned**.
- **Deletion vectors:** Supported on **Dremio Cloud** only; **Dremio self-managed (self-hosted)** does not support reading deletion vectors.
:::

:::note[Other delete format limits (⚠️)]
- **Trino and Starburst:** Deletion vectors need Trino 480 or later, and both vendors still call Iceberg v3 support experimental ([Trino Iceberg connector](https://trino.io/docs/current/connector/iceberg.html), [Starburst Iceberg connector](https://docs.starburst.io/latest/connector/iceberg.html), checked Nov 2026).
- **Presto:** Equality deletes need Java workers. Presto C++ (native) workers do not read them ([Presto Iceberg connector docs](https://github.com/prestodb/presto/blob/master/presto-docs/src/main/sphinx/connector/iceberg.rst), checked Nov 2026).
- **Apache Hive:** The Hive 4.2.0 release notes list deletion vector support ([Hive downloads](https://hive.apache.org/general/downloads/), checked Nov 2026). OLake Go does not offer deletion vectors when Hive is a target query engine.
- **Apache Impala:** The Impala docs say it supports only position delete files, while the 4.4.0 changelog adds basic equality delete support ([Impala Iceberg docs](https://impala.apache.org/docs/build/html/topics/impala_iceberg.html), [Impala 4.4.0 changelog](https://impala.apache.org/docs/changelog-4.4.0.html), checked Nov 2026). The newest Impala release is 4.5.3.
- **DuckDB:** Deletion vectors arrived in duckdb-iceberg 1.5.3 ([DuckDB blog](https://duckdb.org/2026/05/29/new-iceberg-features), checked Nov 2026). The DuckDB docs do not cover equality delete reads.
- **ClickHouse:** Deletion vector reads shipped in 26.10 as an experimental feature, and the 26.8 long-term support (LTS) release does not read them ([ClickHouse changelog](https://clickhouse.com/docs/whats-new/changelog), checked Nov 2026).
- **Apache Doris:** Deletion vectors need Doris 4.1.0 or later ([Doris Iceberg catalog](https://doris.apache.org/docs/lakehouse/catalogs/iceberg-catalog), checked Nov 2026).
- **BigQuery:** Iceberg v3 support, including binary deletion vectors, is in Preview ([BigQuery Iceberg external tables](https://docs.cloud.google.com/bigquery/docs/iceberg-external-tables), checked Nov 2026). OLake Go does not offer deletion vectors when BigQuery is a target query engine.
- **AWS Redshift:** Redshift reads Iceberg v3 tables, and so deletion vectors, only on Serverless or on RG clusters, and it cannot use v3 tables that contain equality deletes ([Redshift Iceberg v3 features](https://docs.aws.amazon.com/redshift/latest/dg/iceberg-v3-features.html), checked Nov 2026). Amazon S3 lists patch 204 or later for v3 reads ([S3 Iceberg v3 support](https://docs.aws.amazon.com/AmazonS3/latest/userguide/working-with-apache-iceberg-v3.html), checked Nov 2026).
- **Spark, Flink and Synapse:** Deletion vector reads come with Iceberg 1.8.0 or later on the classpath ([Iceberg releases](https://iceberg.apache.org/releases/), checked Nov 2026). Spark 3.3 and Flink 1.18 and 1.19 are end of life in Iceberg ([multi-engine support](https://iceberg.apache.org/multi-engine-support/), checked Nov 2026).
:::

:::info[Delete Format Notes]
- **Equality deletes and positional deletes** are Iceberg v2 row-level delete formats.
- **Deletion vectors** is Iceberg v3 row-level delete format.
:::

### How OLake Go picks the delete format

OLake Go preselects the first of equality deletes, positional deletes and deletion vectors that every engine in the job's [Target Query Engines](/docs/getting-started/job-level-properties/#target-query-engines) reads. OLake Go's list holds Apache Spark, Apache Flink, Trino, Presto, StarRocks, Apache Hive, DuckDB, AWS Athena, Snowflake, Google BigQuery, Databricks, Dremio and ClickHouse. Starburst, Impala, Doris, Redshift and Synapse are readers only: list an engine that reads the same formats, or none, and check the upsert type by hand.

Since [v1.1.2](/docs/release/ingestion/v1.1.0), OLake Go also narrows the formats by destination catalog. Nessie gets no deletion vectors, Unity Catalog gets deletion vectors only, and Snowflake Horizon gets positional deletes or deletion vectors. When no format is left, the streams run in append mode.
