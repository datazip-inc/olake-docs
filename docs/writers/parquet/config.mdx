# S3 Parquet

OLake Go writes Parquet through the Amazon S3 connector. **Storage Type** selects S3-compatible storage (AWS S3, GCS, or MinIO) or Azure. Before proceeding, review the [Getting Started](/docs/getting-started/quickstart) and [Installation](/docs/install/olake-ui) sections.

OLake Go supports writing in parquet format directly to S3. Before proceeding with the S3 Parquet destination, we recommend reviewing the [Getting Started](/docs/getting-started/quickstart) and [Installation](/docs/install/olake-ui) sections.

---

## Prerequisites
- Before setting up the destination, make sure you have successfully set up the [`source`](/docs/getting-started/creating-first-pipeline#2-configure-source).
- **AWS S3:** Review the minimum required [IAM Permissions for S3 Parquet Writer](/docs/writers/parquet/permission).
- **GCS:** Review [GCP IAM Permission](/docs/writers/parquet/permission#2-gcs-google-cloud-storage-iam-policy) for role-based access, and create HMAC keys for your service account to use as S3 credentials. See [Creation of HMAC Keys](https://docs.cloud.google.com/storage/docs/authentication/hmackeys) below.

2. OLake Go creates a test folder named `olake_writer_test` containing a single text file (`.txt`) with the content:

## Configuration

Configure the following fields to write Parquet files to Azure.

### Authentication

It supports multiple authentication types. Select the authentication mechanism your storage account uses.

<Tabs queryString="azure-auth-type" groupId="parquet-azure-auth">

<TabItem value="connection-string" label="Connection String" default>

To use **Connection String** authentication, create a storage account connection string in Azure first. Follow the steps in the [Configure Azure Storage connection strings](https://learn.microsoft.com/en-us/azure/storage/common/storage-configure-connection-string) documentation before configuring OLake Go.

<Tabs queryString="tab">

<TabItem value="azure-ui" label="OLake UI" default>

![OLake S3 destination config fields and reference guide.](/img/docs/s3/azure-conn-string.webp)

**Connection String Configuration Parameters:**

| Parameter | Sample Value | Description |
|-----------|--------------|-------------|
| **Storage Type** | `Azure` | Storage backend OLake Go uses to write Parquet files. Set to Azure to write to Azure Blob Storage. |
| **Azure Auth Type** <br/> `required` | `Connection String` | Authentication method OLake Go uses for Azure Blob requests. Set to match your storage account's authentication requirement. |
| **Azure Storage Container Name** <br/> `required` | `olake-data` | Name of an existing Azure storage container with permission to store output files. |
| **Azure Path** | `/data` | Path inside the container where data files are written. |
| **Azure Endpoint** | `https://<ACCOUNT_NAME>.blob.core.windows.net/` | Blob service URL. Leave empty to use `https://{account}.blob.core.windows.net/`. <br/> <br/> For Azurite, use `http://<host>:<port>/<account>`. |
| **Azure Connection String** <br/> `required` | `DefaultEndpointsProtocol=https;AccountName=<ACCOUNT_NAME>;AccountKey=<ACCOUNT_KEY>;EndpointSuffix=core.windows.net` | Storage account connection string. Includes AccountName, AccountKey, and EndpointSuffix. |
| **Max File Size (MB)** | `512` | Rolls a partition into a new parquet file once the current file reaches this size in MB. Fractional values are allowed. Defaults to `512` when unset. |

</TabItem>

<TabItem value="shared-key" label="Shared Key">

To use **Shared Key** authentication, copy the storage account name and an account access key from Azure. Follow the steps in the [Manage storage account access keys](https://learn.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage) documentation before configuring OLake Go.

<Tabs queryString="tab">

<TabItem value="azure-ui" label="OLake UI" default>

![OLake S3 destination config fields and reference guide.](/img/docs/s3/azure-shared-key.webp)

**Shared Key Configuration Parameters:**

| Parameter | Sample Value | Description |
|-----------|--------------|-------------|
| **Storage Type** | `Azure` | Storage backend OLake Go uses to write Parquet files. Set to Azure to write to Azure Blob Storage. |
| **Azure Auth Type** <br/> `required` | `Shared Key` | Authentication method OLake Go uses for Azure Blob requests. Set to match your storage account's authentication requirement. |
| **Azure Storage Account Name** <br/> `required` | `olakedata` | Name of the Azure storage account that contains the container. |
| **Azure Storage Container Name** <br/> `required` | `olake-data` | Name of an existing Azure storage container with permission to store output files. |
| **Azure Path** | `/data` | Path inside the container where data files are written. |
| **Azure Endpoint** | `https://<ACCOUNT_NAME>.blob.core.windows.net/` | Blob service URL. Leave empty to use `https://{account}.blob.core.windows.net/`. <br/> <br/> For Azurite, use `http://<host>:<port>/<account>`. |
| **Azure Storage Account Key** <br/> `required` | `<ACCOUNT_KEY>` | Access key for the Azure storage account. OLake Go uses this with the account name to sign Blob requests. |
| **Max File Size (MB)** | `512` | Rolls a partition into a new parquet file once the current file reaches this size in MB. Fractional values are allowed. Defaults to `512` when unset. |

</TabItem>
