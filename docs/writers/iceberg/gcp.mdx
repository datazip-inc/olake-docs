# Google Cloud Storage (GCS) Writer Overview

OLake Go writes Iceberg tables to Google Cloud Storage (GCS) through either of two catalogs:

- **[BigLake REST catalog](/docs/writers/iceberg/catalog/rest/?rest-catalog=biglake)** (OLake Go v0.9.1 and later). BigLake is Google Cloud's managed Iceberg REST catalog, and OLake Go signs in with a service account key. BigQuery reads the tables in place, with each namespace as a dataset; [Postgres to BigQuery](/docs/integrations/postgres-to-bigquery/) shows a full run.
- **[Hive Metastore, such as Dataproc Metastore](/docs/writers/iceberg/catalog/hive#gcp-dataproc-metastore)**. Set `iceberg_s3_path` to a `gs://` bucket path. Spark on Dataproc reads these tables, but BigQuery does not see them.

The [BigLake catalog page](/docs/integrations/catalogs/biglake/) lists the engines that read BigLake tables. To write Parquet files to GCS instead of Iceberg tables, see the [Parquet GCS writer](/docs/writers/parquet/gcs/).
