:::info[NaN and timezone handling]
- A `numeric` column can hold `NaN`, which a `decimal` column cannot. OLake Go writes it as null and logs one warning for the sync.
- OLake Go always ingests timestamp data in UTC format, independent of the source timezone.
:::
