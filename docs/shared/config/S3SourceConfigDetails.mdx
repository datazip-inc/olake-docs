| Field | Description | Example Value | Type |
|-------|-------------|---------------|------|
| bucket_name `required` | Name of the S3 bucket that contains the files to sync. | `"my-data-warehouse"` | String |
| region | AWS Region where your S3 bucket exists, so OLake Go calls the correct regional S3 endpoint. Required for AWS S3; optional when `endpoint` is set. | `"us-east-1"` | String |
| path_prefix | Optional path prefix to filter files | `"data"` | String |
| access_key_id | AWS access key ID for authentication. Optional if using IAM roles or instance profiles. | `"<YOUR_KEY>"` | String |
| secret_access_key | AWS secret access key for authentication. Optional if using IAM roles or instance profiles. | `"<YOUR_SECRET>"` | String |
| endpoint | Custom S3 endpoint for MinIO/LocalStack (required for non-AWS) | `"http://localhost:9000"` | String |
| file_format `required` | Select the format of files in the bucket to sync. OLake Go uses this to determine how to read and process files during sync. Values are lowercase and case-sensitive: `"Parquet"` fails with `invalid file_format`. | <ul> <li>`csv`</li> <li>`json`</li> <li>`parquet`</li> <li>`xml`</li> </ul> | String |
| max_threads | Maximum number of worker threads the connector can spin up for parallel tasks. | `10` | Integer |
| retry_count | Number of retry attempts for failures. | `3` | Integer |
| compression | Compression format of the files. Default `none`, which skips `.gz` files. Set `gzip` to include `.gz` files (plain files are still read; Parquet is never matched as `.gz`). `zip` passes validation but is not supported yet: zip archives are never decompressed or discovered. | <ul> <li>`none`</li> <li>`gzip`</li> </ul> | String |
| file_pattern | Regular expression to filter files by name. | `.*\.csv$` | String |
