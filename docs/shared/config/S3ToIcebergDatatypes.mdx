:::info[Parquet decimal schema]
OLake Go takes a stream's schema from its first Parquet file. From OLake Go **v1.2.0**, a later file that declares the same column with another decimal scale, or as `FLOAT` or `DOUBLE`, fails the stream. Before, both landed as `double`.
:::

:::info[Schema Inference]
- **CSV**: Uses AND logic - examines all sampled rows to determine most restrictive type
- **JSON**: Auto-detects types from JSON primitives
- **Parquet**: Schema read directly from file metadata (no inference needed)
- **XML**: Values are strings, except date and datetime text, which becomes timestamptz. Nested elements stored as JSON strings.
:::

:::info[timestamptz timezone]
OLake Go always ingests timestamp data in UTC format, independent of the source timezone.
:::
