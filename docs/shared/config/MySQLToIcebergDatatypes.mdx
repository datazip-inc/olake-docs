:::info[Binary columns]
The `fixed[n]` and `binary` mappings apply to jobs created on OLake Go v0.12.2 or later. Older jobs keep these columns as `string`. In the CLI, a first sync run with an empty `{}` state file also keeps them as `string`, so run the first sync without `--state`.
:::

:::warning[BIGINT UNSIGNED overflow]
`BIGINT UNSIGNED` values above 9,223,372,036,854,775,807 wrap to negative numbers, for example 18446744073709551615 lands as `-1`.
:::

:::info[INT UNSIGNED mapping change]
From OLake Go version `0.4.1` and above, `INT UNSIGNED` maps to `bigint` in the destination. In versions earlier than `0.4.1`, it maps to `int`.
:::

:::info[timestamptz timezone]
OLake Go always ingests timestamp data in UTC format, independent of the source timezone.
:::
