:::info[Streams v2 is here]
Streams config now uses two files: `selected_streams.json` (the file you edit) and `available_streams.json` (read-only, written by discover).
See the [migration guide](/docs/core/configs/streams-migration) to migrate to Streams v2 from Streams v1 or the [Streams v1 reference](/docs/core/configs/streams-legacy) for more details on the legacy format.
:::
