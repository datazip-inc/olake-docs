:::info[Streams v2 is here]
Streams config now uses two files: `selected_streams.json` (the file you edit) and `available_streams.json` (read-only, written by discover).
Streams v1 (legacy `streams.json`) is deprecated.
See the [migration guide](/docs/core/configs/streams-migration), the [streams reference](/docs/core/configs/streams), or the [Streams v1 reference](/docs/core/configs/streams-legacy).
:::
