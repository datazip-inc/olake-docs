Open source Spark reaches Polaris through the Iceberg REST catalog. The `warehouse` is the Polaris catalog name, and `credential` is the principal's client ID and secret, which Spark trades for an OAuth2 token.

```bash title="spark-sql against Polaris"
spark-sql \
  --packages org.apache.iceberg:iceberg-spark-runtime-3.5_2.12:1.10.0,org.apache.iceberg:iceberg-aws-bundle:1.10.0 \
  --conf spark.sql.extensions=org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions \
  --conf spark.sql.catalog.polaris=org.apache.iceberg.spark.SparkCatalog \
  --conf spark.sql.catalog.polaris.type=rest \
  --conf spark.sql.catalog.polaris.uri=http://<polaris-host>:8181/api/catalog \
  --conf spark.sql.catalog.polaris.warehouse=olake \
  --conf spark.sql.catalog.polaris.credential=<client_id>:<client_secret> \
  --conf spark.sql.catalog.polaris.scope=PRINCIPAL_ROLE:ALL \
  --conf spark.sql.catalog.polaris.header.X-Iceberg-Access-Delegation=vended-credentials \
  --conf spark.sql.catalog.polaris.client.region=us-east-1
```

<CodeBlock language="sql">{`SELECT ${props.idCol ?? 'id'}, name, city, tier FROM polaris.${props.schema ?? 'postgres_to_iceberg_shop_public'}.customers ORDER BY ${props.idCol ?? 'id'};`}</CodeBlock>

On MinIO or another S3-compatible store, also set `spark.sql.catalog.polaris.s3.endpoint` and `spark.sql.catalog.polaris.s3.path-style-access=true`. The run on this page used Spark 3.5.6 with Iceberg 1.10.0 against MinIO, with the MinIO keys passed as `s3.access-key-id` and `s3.secret-access-key` instead of vended credentials.
