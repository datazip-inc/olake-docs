Open source Spark reaches Unity Catalog as a plain Iceberg REST catalog. The `warehouse` is the catalog name, the token is a personal access token, and the `X-Iceberg-Access-Delegation` header asks Unity Catalog for short-lived storage credentials.

```bash title="spark-sql against Unity Catalog"
spark-sql \
  --packages org.apache.iceberg:iceberg-spark-runtime-4.0_2.13:1.10.0,org.apache.iceberg:iceberg-gcp-bundle:1.10.0 \
  --conf spark.sql.extensions=org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions \
  --conf spark.sql.catalog.uc=org.apache.iceberg.spark.SparkCatalog \
  --conf spark.sql.catalog.uc.type=rest \
  --conf spark.sql.catalog.uc.uri=https://<workspace-url>/api/2.1/unity-catalog/iceberg-rest \
  --conf spark.sql.catalog.uc.warehouse=lakehouse \
  --conf spark.sql.catalog.uc.token=<personal access token> \
  --conf spark.sql.catalog.uc.header.X-Iceberg-Access-Delegation=vended-credentials
```

Iceberg 1.8 or later reads the v3 deletion vectors OLake Go writes for Databricks; this page was tested with 1.10.0 on Spark 4.0.1. Swap `iceberg-gcp-bundle` for `iceberg-aws-bundle` or `iceberg-azure-bundle` to match the cloud the workspace runs on.
