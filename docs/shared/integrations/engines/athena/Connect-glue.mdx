Athena reads the Glue Data Catalog natively: the Glue database OLake Go created shows up in the query editor's database list, and the Iceberg tables in it need no registration and no refresh. Pick a workgroup with a query result location in S3, select the database, and query.

<CodeBlock language="sql" title="Athena query editor (database: the one OLake Go created)">{`SELECT ${props.key ?? 'id'}, name, city, tier FROM ${props.schema ?? 'postgres_to_redshift_shop_public'}.customers ORDER BY ${props.key ?? 'id'};
SELECT status, count(*) AS n, ${props.amount ?? 'round(sum(amount), 2)'} AS total
FROM ${props.schema ?? 'postgres_to_redshift_shop_public'}.orders GROUP BY status ORDER BY status;`}</CodeBlock>

Athena engine v3 reads Iceberg v2 tables with positional and equality deletes, and cannot read v3 tables at all. Keep the job on positional or equality deletes, never deletion vectors, while Athena is a reader. From the command line, `aws athena start-query-execution --work-group <workgroup> --query-execution-context Database=${props.schema ?? 'postgres_to_redshift_shop_public'} --query-string "..."` runs the same queries; `aws athena get-query-results` returns the rows.
