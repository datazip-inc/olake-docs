<TabItem value="ui" label="OLake UI" default>

1. Open **Destinations** and click **Create Destination**.
2. Pick **Apache Iceberg** as the connector and **Generic REST** as the catalog type.
3. Set **REST Catalog URI** to the AIStor catalog (`http://<aistor-host>:9000/_iceberg`), **S3 Path** to the warehouse name (`olake`), **S3 Endpoint** to the AIStor S3 address (`http://<aistor-host>:9000`), and **REST Auth Type** to `sigv4`.
4. Fill in **AWS Access Key** and **AWS Secret Key** with the AIStor access key, **AWS Region** with `us-east-1`, **REST Signing Name** with `s3tables` and **REST Signing Region** with `us-east-1`, and switch on **REST Enable Signature V4**.
5. Click **Create**. OLake Go signs a request to the catalog, creates a test table in the warehouse, writes a file to AIStor and drops the table again.

<TabItem value="cli" label="OLake CLI">

Create `destination.json` next to `source.json`:

```json title="destination.json"
{
  "type": "ICEBERG",
  "writer": {
    "catalog_type": "rest",
    "catalog_name": "aistor",
    "rest_catalog_url": "http://<aistor-host>:9000/_iceberg",
    "iceberg_s3_path": "olake",
    "rest_auth_type": "sigv4",
    "rest_signing_v_4": true,
    "rest_signing_name": "s3tables",
    "rest_signing_region": "us-east-1",
    "aws_region": "us-east-1",
    "s3_endpoint": "http://<aistor-host>:9000",
    "s3_path_style": true,
    "aws_access_key": "<access-key>",
    "aws_secret_key": "<secret-key>"
  }
}
```

`iceberg_s3_path` holds the warehouse name, not a bucket path: AIStor decides where the table files go inside the warehouse. `s3_path_style` keeps the bucket in the URL path, which AIStor expects.
