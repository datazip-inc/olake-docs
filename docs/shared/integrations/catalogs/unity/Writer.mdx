<TabItem value="ui" label="OLake UI" default>

1. Open **Destinations** and click **Create Destination**.
2. Pick **Apache Iceberg** as the connector and **Unity** as the catalog type.
3. Choose **Personal Access Token** as the authentication type and fill in the fields below. The catalog name from the setup goes into the catalog field.
4. Click **Create**. OLake Go calls the Unity Catalog endpoint with the token and saves the destination.

<TabItem value="cli" label="OLake CLI">

Create `destination.json` next to `source.json`:

```json title="destination.json"
{
  "type": "ICEBERG",
  "writer": {
    "catalog_type": "unity",
    "catalog_name": "olake_iceberg",
    "rest_catalog_url": "https://<workspace-url>/api/2.1/unity-catalog/iceberg-rest",
    "iceberg_s3_path": "lakehouse",
    "rest_auth_type": "personal access token",
    "token": "<personal access token>",
    "arrow_writes": false
  }
}
```

`iceberg_s3_path` holds the Unity Catalog catalog name, not a bucket path: Unity Catalog decides where the files go.
