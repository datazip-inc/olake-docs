<TabItem value="ui" label="OLake UI" default>

1. Open **Destinations** and click **Create Destination**.
2. Pick **Apache Iceberg** as the connector and **Polaris** as the catalog type.
3. Choose **OAuth2** as the authentication type. **REST Catalog URI** is the Polaris catalog endpoint (`http://<polaris-host>:8181/api/catalog`), **Polaris Catalog Name** the catalog from the setup (`olake`), **REST Auth URI** the token endpoint, and **REST Credential** the principal's `<client_id>:<client_secret>`.
4. Fill in the store: **AWS Region**, and for MinIO the **S3 Endpoint** with the **AWS Access Key** and **AWS Secret Key**. On AWS S3 leave the endpoint empty.
5. Click **Create**. OLake Go exchanges the credentials for a token, creates a namespace and a test table through Polaris, writes to the bucket and drops the test table again.

<TabItem value="cli" label="OLake CLI">

Create `destination.json` next to `source.json`:

```json title="destination.json"
{
  "type": "ICEBERG",
  "writer": {
    "catalog_type": "polaris",
    "catalog_name": "polaris",
    "rest_catalog_url": "http://<polaris-host>:8181/api/catalog",
    "iceberg_s3_path": "olake",
    "rest_auth_type": "oauth2",
    "oauth2_uri": "http://<polaris-host>:8181/api/catalog/v1/oauth/tokens",
    "credential": "<client_id>:<client_secret>",
    "scope": "PRINCIPAL_ROLE:ALL",
    "aws_region": "us-east-1",
    "s3_endpoint": "http://<minio-host>:9000",
    "aws_access_key": "<minio access key>",
    "aws_secret_key": "<minio secret key>",
    "arrow_writes": false
  }
}
```
