<TabItem value="ui" label="OLake UI" default>

1. Open **Destinations** and click **Create Destination**.
2. Pick **Apache Iceberg** as the connector and **BigLake** as the catalog type.
3. Fill in the fields below. The catalog path is the bucket, with no folder after it. Paste the whole service account JSON file into the credentials field.
4. Click **Create**. OLake Go calls the BigLake endpoint, creates the catalog if it is the first contact, and writes and drops a test table in the bucket.

{props.children}

<div className="olake-int-config">

| Field | Value on this page | What it is |
| --- | --- | --- |
| **REST Catalog URI** | `https://biglake.googleapis.com/iceberg/v1/restcatalog` | The BigLake Iceberg REST endpoint. The same for every project and region. |
| **BigLake Catalog Path** | `gs://<bucket>` | The bucket that holds the tables. The bucket name is also the catalog name BigQuery uses. Bucket root only; a folder after it is not supported. |
| **Authentication Type** | `GCP` | Google OAuth through the service account. The only choice for BigLake. |
| **GCP Service Account JSON** | the key file contents | Used for both the catalog calls and the Cloud Storage writes. |
| **Catalog Name** | `olake_iceberg` | A label OLake Go uses in its own logs. Lowercase letters and underscores only. |
| **GCP Auth Scopes** | `https://www.googleapis.com/auth/cloud-platform` | The OAuth scope on the token. Leave the default. |
| **GCP Project ID** | the project ID | Routes and bills the catalog calls. Required for multi-bucket catalogs, harmless to set for a single bucket. |
| **Enable Arrow Writes** | off | Keeps the default Java writer, which is what this page was tested with. |

</div>

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `destination.json` next to `source.json`. The service account JSON goes in as one escaped string.

```json title="destination.json"
{
  "type": "ICEBERG",
  "writer": {
    "catalog_type": "biglake",
    "catalog_name": "olake_iceberg",
    "rest_catalog_url": "https://biglake.googleapis.com/iceberg/v1/restcatalog",
    "iceberg_s3_path": "gs://<bucket>",
    "rest_auth_type": "org.apache.iceberg.gcp.auth.GoogleAuthManager",
    "gcp_service_account_json": "{\"type\": \"service_account\", ...}",
    "gcp_project_id": "<project-id>",
    "gcp_auth_scopes": "https://www.googleapis.com/auth/cloud-platform",
    "arrow_writes": false
  }
}
```

<div className="olake-int-config">

| Key | Value on this page | What it is |
| --- | --- | --- |
| `catalog_type` | `biglake` | Selects the BigLake REST catalog. |
| `rest_catalog_url` | `https://biglake.googleapis.com/iceberg/v1/restcatalog` | The BigLake endpoint. |
| `iceberg_s3_path` | `gs://<bucket>` | The bucket, which is also the catalog name in BigQuery. The key is named for S3 but takes a `gs://` path here. |
| `rest_auth_type` | `org.apache.iceberg.gcp.auth.GoogleAuthManager` | Google OAuth with the service account. |
| `gcp_service_account_json` | the key file as a string | Credentials for the catalog and the bucket. |
| `gcp_project_id` | the project ID | Routes and bills the catalog calls. |
| `gcp_auth_scopes` | `https://www.googleapis.com/auth/cloud-platform` | The OAuth scope. |
| `rest_access_delegation` | not set | Set it to `vended-credentials` only when the catalog is in vended-credentials mode. The UI has no field for it. |
| `arrow_writes` | `false` | The default Java writer. |

</div>
