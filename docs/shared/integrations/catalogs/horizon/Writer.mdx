<TabItem value="ui" label="OLake UI" default>

1. Open **Destinations** and click **Create Destination**.
2. Pick **Apache Iceberg** as the connector and **Horizon** as the catalog type.
3. Choose **Programmatic Access Token (PAT)** as the authentication type and fill in the fields below.
4. Click **Create**. OLake Go calls the Horizon endpoint, exchanges the token and saves the destination.

<TabItem value="cli" label="OLake CLI">

Create `destination.json` next to `source.json`. `iceberg_s3_path` holds the Snowflake database name (not an S3 path: the storage is Snowflake-managed) and `aws_region` holds the Snowflake region string from `CURRENT_REGION()`.

```json title="destination.json"
{
  "type": "ICEBERG",
  "writer": {
    "catalog_type": "horizon",
    "catalog_name": "horizon",
    "rest_catalog_url": "https://<account_identifier>.snowflakecomputing.com/polaris/api/catalog",
    "iceberg_s3_path": "OLAKE_DEMO",
    "aws_region": "AWS_AP_SOUTH_1",
    "scope": "session:role:OLAKE_ROLE",
    "rest_auth_type": "Programmatic Access Token (PAT)",
    "credential": "<your PAT>",
    "arrow_writes": false
  }
}
```
