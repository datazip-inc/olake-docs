<TabItem value="ui" label="OLake UI" default>

1. Open **Jobs** and click **Create Job**. Give it a name and a schedule. **Every Day** at a fixed hour, or a cron expression, both work; the schedule is how often the change stream is drained, not how often a full copy runs.
2. Select the source and the destination you created.
3. Under **Advanced Settings**, set **Target Query Engines** to {props.engines ?? 'the engines that will read the tables'}. OLake Go then offers only the upsert types every one of those engines can read, so a job cannot be saved in a format its readers cannot open.
4. Click **Next**. OLake Go discovers the tables and opens the **Streams** page.
5. Tick the tables to replicate. For each one, set the sync mode to **Full Refresh + CDC** and the ingestion mode to **Upsert**, and check that the **Upsert Type** reads {props.upsert ?? 'the format your engines read'}.
6. Click **Create Job**, then open the job's menu and choose **Sync Now** for the first run.

<TabItem value="cli" label="OLake CLI">

Discover the tables, edit the stream settings, then sync:

```bash title="discover"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-postgres:latest \
  discover --config /mnt/config/source.json
```

`discover` writes `streams.json`. For each table you want, set the sync mode to `cdc` in its `stream` block and the upsert type for your readers in `selected_streams`:

<CodeBlock language="json" title="streams.json (one selected stream)">{`{
  "selected_streams": {
    "public": [
      {
        "stream_name": "customers",
        "normalization": true,
        "append_mode": false,
        "update_type": "${props.updateType ?? 'pos'}"
      }
    ]
  }
}`}</CodeBlock>

`update_type` accepts `eq` (equality deletes, the default), `pos` (positional deletes) and `dv` (deletion vectors). On the first run, leave out the last line (`--state`): `state.json` does not exist yet, and OLake Go writes it during the sync. Every later run uses the full command and syncs only the changes:

```bash title="sync"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-postgres:latest \
  sync \
  --config /mnt/config/source.json \
  --catalog /mnt/config/streams.json \
  --destination /mnt/config/destination.json \
  --state /mnt/config/state.json
```

Positional deletes and deletion vectors need a persistent index directory between runs. Set `OLAKE_INDEX_DB_DIR` to a mounted path (the UI's Docker Compose does this for you); see [index DB setup](/docs/install/olake-ui/#index-db-setup-for-positional-delete-deletion-vector-writes). The full `streams.json` reference is on the [Docker CLI page](/docs/install/docker-cli/#streams-config).
