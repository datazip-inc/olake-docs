<TabItem value="ui" label="OLake UI" default>

1. Open **Jobs** and click **Create Job**. Give it a name and a schedule. **Every Day** at a fixed hour, or a cron expression, both work; the schedule is how often the change stream is drained, not how often a full copy runs.
2. Select the source and the destination you created.
3. Under **Advanced Settings**, set **Target Query Engines** to {props.engines ?? 'the engines that will read the tables'}. OLake Go then resolves an Iceberg delete format every one of those engines can read, so you never pick one by hand.
4. Click **Next**. OLake Go discovers the tables and opens the **Streams** page.
5. Tick the tables to replicate. For each one, set the sync mode to **Full Refresh + CDC** and the ingestion mode to **Upsert**. Leave the **Upsert Type** as OLake Go resolved it{props.upsert ? ` (${props.upsert} in the run on this page)` : ''}.
6. Click **Create Job**, then open the job's menu and choose **Sync Now** for the first run.

<TabItem value="cli" label="OLake CLI">

Discover the tables, choose the streams, then sync:

```bash title="discover"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-postgres:latest \
  discover --config /mnt/config/source.json
```

`discover` writes two files: `available_streams.json` (every table it found, do not edit) and `selected_streams.json` (the tables you want and their settings). In `selected_streams.json`, set `sync_mode` to `cdc` for each table and pick the delete format your readers can open:

<CodeBlock language="json" title="selected_streams.json (one selected stream)">{`{
  "selected_streams": {
    "public": [
      {
        "stream_name": "customers",
        "sync_mode": "cdc",
        "normalization": true,
        "append_mode": false,
        "update_type": "${props.updateType ?? 'pos'}"
      }
    ]
  }
}`}</CodeBlock>

`update_type` accepts `eq` (equality deletes, the default), `pos` (positional deletes) and `dv` (deletion vectors). Positional deletes and deletion vectors keep a small index between runs, so give the container a persistent directory for it through `OLAKE_INDEX_DB_DIR`. The first sync runs without a state file; OLake Go writes one at the end of the run:

```bash title="first sync"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  -e OLAKE_INDEX_DB_DIR=/mnt/config/index-db \
  olakego/source-postgres:latest \
  sync \
  --config /mnt/config/source.json \
  --selected-streams /mnt/config/selected_streams.json \
  --available-streams /mnt/config/available_streams.json \
  --destination /mnt/config/destination.json
```

Every later run adds `--state /mnt/config/state.json` to the same command, which is how OLake Go knows to replay only the changes since the last run. The full `selected_streams.json` reference is on the [Docker CLI page](/docs/install/docker-cli/#streams-config); the index directory is described under [index DB setup](/docs/install/olake-ui/#index-db-setup-for-positional-delete-deletion-vector-writes).
