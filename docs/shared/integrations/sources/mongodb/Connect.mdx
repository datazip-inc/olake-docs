<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **MongoDB** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Under **Change data capture (CDC)**, leave **Enable CDC** on.
3. Under **Connection details**, add each host as `host:port` (or one SRV host with **Use SRV** on for Atlas), then the **Database Name**, **Auth DB** (`admin`), username, password and the **Replica Set** name. Leave **Read Preference** on `primary` unless you have secondaries to spare.
4. Click **Set up source**. OLake Go tests the connection, confirms that it can open a change stream, and reports the oplog window with a warning below 7 days.

{props.children}

The full field reference, including SRV strings, IAM authentication and SSH tunnels, is on the [MongoDB connector page](/docs/connectors/mongodb/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. `replica_set` is what lets OLake Go open the change stream:

<MongoDBSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-mongodb:latest \
  check --config /mnt/config/source.json
```

A working setup returns `"status": "SUCCEEDED"` with a `prerequisites` list that reports `change_streams` as passed and the `oplog_retention` window. Every field is described on the [MongoDB connector page](/docs/connectors/mongodb/?config-type=olake-cli#configuration).
