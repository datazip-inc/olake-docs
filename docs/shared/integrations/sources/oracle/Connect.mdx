<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **Oracle** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Fill in the host and port, choose **Service Name** (or **SID**) as the connection type and enter it, then the username and password from step 1. Type the username the way Oracle stores it, which is upper case unless you created it in double quotes: OLake Go quotes the name when it connects, so `olake` and `OLAKE` are different users.
3. Click **Set up source**. OLake Go tests the connection and saves the source.

{props.children}

The full field reference, including SSL and SSH tunnels, is on the [Oracle connector page](/docs/connectors/oracle/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder with either `service_name` or `sid`:

<OracleSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-oracle:latest \
  check --config /mnt/config/source.json
```

A working connection returns `"status": "SUCCEEDED"`. Every field is described on the [Oracle connector page](/docs/connectors/oracle/?config-type=olake-cli#configuration).
