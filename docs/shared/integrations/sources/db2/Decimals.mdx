:::info[Decimal columns]
This page was tested on OLake Go <TestedVersion />. From **v1.2.0**, new jobs write `DECIMAL` and `NUMERIC` as exact `decimal(p,s)`. An existing job keeps floating point after upgrading, until you run [Clear Destination](/docs/getting-started/job-level-properties/#8-clear-destination), which recreates its tables with decimals.
:::
