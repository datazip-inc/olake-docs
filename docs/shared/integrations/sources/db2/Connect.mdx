<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **DB2 LUW** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Fill in the host, the port (`50000` by default), the database name, and the username and password from step 1. The **Enable CDC** switch stays off: DB2 runs in incremental mode only.
3. Click **Set up source**. OLake Go tests the connection and saves the source.

{props.children}

The full field reference, including SSL and SSH tunnels, is on the [DB2 connector page](/docs/connectors/db2/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder:

<DB2SourceConfig />

Then confirm OLake Go can reach the database. `--platform linux/amd64` lets the amd64-only image run on an Apple silicon Mac and changes nothing on an amd64 host:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  --platform linux/amd64 \
  olakego/source-db2:latest \
  check --config /mnt/config/source.json
```

A working connection returns `"status": "SUCCEEDED"`. Every field is described on the [DB2 connector page](/docs/connectors/db2/?config-type=olake-cli#configuration).
