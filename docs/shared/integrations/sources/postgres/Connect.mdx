<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **Postgres** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Under **Change data capture (CDC)**, leave **Enable CDC** on and enter the **Replication Slot** and **Publication** you created in step 1. The default **Initial Wait Time** is fine.
3. Under **Connection details**, fill in the host, port, database name, username and password. Leave **Schemas** empty to discover every non-system schema, or list the ones you want.
4. Click **Set up source**. OLake Go tests the connection, then checks the four CDC prerequisites (`wal_level`, the replication privilege, the slot and the publication) and shows the current and recommended value for anything that fails.

{props.children}

The full field reference, including SSL modes and SSH tunnels, is on the [Postgres connector page](/docs/connectors/postgres/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. The `update_method` block is what turns CDC on:

<PostgresSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-postgres:latest \
  check --config /mnt/config/source.json
```

A working setup returns `"status": "SUCCEEDED"` together with a `prerequisites` list that reports `wal_level`, `replication_privilege`, `replication_slot` and `publication` as passed. A failed check names the setting and its recommended value. Every field is described on the [Postgres connector page](/docs/connectors/postgres/?config-type=olake-cli#configuration).
