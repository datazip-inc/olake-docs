<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**.
2. Pick **Postgres** as the connector and keep the OLake Go version on the latest release.
3. Fill in the host, port, database, username and password. Leave **Schemas** empty to discover every non-system schema, or list the ones you want.
4. Set **Update Method** to **CDC**, then enter the **Replication Slot** and **Publication** you created above.
5. Click **Create**. OLake Go tests the connection and saves the source.

The full field reference, including SSL modes and SSH tunnels, is on the [Postgres connector page](/docs/connectors/postgres/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. The `update_method` block is what turns CDC on:

<PostgresSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-postgres:latest \
  check --config /mnt/config/source.json
```

A working connection returns `{"connectionStatus":{"status":"SUCCEEDED"},"type":"CONNECTION_STATUS"}`. Every field is described on the [Postgres connector page](/docs/connectors/postgres/?config-type=olake-cli#configuration).
