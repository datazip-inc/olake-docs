<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **MSSQL** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Under **Change data capture (CDC)**, leave **Enable CDC** on. Turn on **Manage Capture Instance** if you want OLake Go to create a new capture instance by itself after a schema change (it then needs `db_owner`); leave it off to manage capture instances by hand.
3. Under **Connection details**, fill in the host, port, database name, username and password. Keep SSL off for a local test; on hosted SQL Server use the provider's certificate.
4. Click **Set up source**. OLake Go tests the connection, then checks that CDC is on for the database and that the tables have capture instances, and shows the current and recommended value for anything that fails.

{props.children}

The full field reference, including SSL modes and SSH tunnels, is on the [SQL Server connector page](/docs/connectors/mssql/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. The `update_method` block is what turns CDC on:

<MSSQLSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-mssql:latest \
  check --config /mnt/config/source.json
```

A working setup returns `"status": "SUCCEEDED"` together with the CDC prerequisite checks. Every field is described on the [SQL Server connector page](/docs/connectors/mssql/?config-type=olake-cli#configuration).
