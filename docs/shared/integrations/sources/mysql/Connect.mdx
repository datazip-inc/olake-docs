<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **MySQL** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. Under **Change data capture (CDC)**, leave **Enable CDC** on. The default **Initial Wait Time** is fine; raise it only if the binlog is large and the next sync times out while finding its saved position.
3. Under **Connection details**, fill in the host, port, database name, username and password. Keep TLS off for a local test; on managed MySQL use the provider's certificate.
4. Click **Set up source**. OLake Go tests the connection, then checks the binlog prerequisites (`binlog_access`, `log_bin`, `binlog_format`, `binlog_row_metadata`) and shows the current and recommended value for anything that fails.

{props.children}

The full field reference, including SSL and SSH tunnels, is on the [MySQL connector page](/docs/connectors/mysql/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. The `update_method` block is what turns CDC on:

<MySQLSourceConfig />

Then confirm OLake Go can reach the database:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-mysql:latest \
  check --config /mnt/config/source.json
```

A working setup returns `"status": "SUCCEEDED"` together with a `prerequisites` list that reports the binlog settings as passed. Every field is described on the [MySQL connector page](/docs/connectors/mysql/?config-type=olake-cli#configuration).
