<TabItem value="ui" label="OLake UI" default>

1. In the OLake UI, open **Sources** and click **Create Source**. Pick **S3** as the connector, give the source a name and keep the OLake Go version on the latest release.
2. The **Enable CDC** toggle under **Change data capture (CDC)** reads *not supported* for S3 and stays off. Object storage has no change log; the job's **Full Refresh + Incremental** mode on the file modification time is what carries new data.
3. Under **Connection details**, fill in the **S3 Bucket Name**, the **AWS Region**, and the **Path Prefix** that holds the stream folders. On AWS, leave **Access Key ID** and **Secret Access Key** empty to use the role OLake Go runs with; on MinIO or LocalStack fill them in and set **Custom Endpoint** to the service URL.
4. Pick the **File Format**. For CSV, check the delimiter, the header toggle and the quote character; for XML, set the row identifier. **File Pattern** is an optional regular expression on the object key, useful when a prefix mixes formats.
5. Click **Set up source**. OLake Go calls `HeadBucket` with the credentials; a 403 or 404 here means the key, the bucket name or the endpoint is wrong.

{props.children}

The full field reference, including JSON, Parquet and XML options, is on the [S3 connector page](/docs/connectors/s3/#configuration).

</TabItem>
<TabItem value="cli" label="OLake CLI">

Create `source.json` in your config folder. `bucket_name`, `region`, `path_prefix` and `file_format` are the fields that matter; `endpoint` and the static keys are for S3-compatible stores:

<S3SourceConfigCSV />

Then confirm OLake Go can reach the bucket:

```bash title="check command"
docker run --pull=always \
  -v "$PWD/config:/mnt/config" \
  olakego/source-s3:latest \
  check --config /mnt/config/source.json
```

A working setup returns `"status": "SUCCEEDED"`. A wrong key returns `failed to access bucket <name>: operation error S3: HeadBucket, https response error StatusCode: 403`; a wrong bucket name the same message with `StatusCode: 404`. Every field is described on the [S3 connector page](/docs/connectors/s3/?config-type=olake-cli#configuration).
