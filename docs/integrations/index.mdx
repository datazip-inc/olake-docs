Each guide here covers one source and one query engine. We ran every pipeline end to end before writing the page. You get the real OLake Go settings, the real query and a screenshot of its result.

**Short answer.** OLake Go copies a database into Apache Iceberg tables in a catalog that your query engine reads. One copy of the data then serves Snowflake, Databricks, BigQuery, DuckDB, Spark and Trino at once. Pick your engine below and follow its guide from setup to the first query result.

<TLDR title='Key takeaways'>

- 49 tested guides cover Postgres, MySQL, MariaDB, MongoDB, Oracle, SQL Server, DB2, Kafka and S3 as sources.
- Each guide ran a first sync and a change sync, and shows the rows the engine returned.
- Every guide lists the catalogs it offers, the one it tested, and the Iceberg delete format the engine reads.

</TLDR>
