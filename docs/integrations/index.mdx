Each guide here is one source, one query engine, and a pipeline that was run end to end before the page was written: the real OLake Go configuration, the real query, and a screenshot of its result. The pattern is the same on every page. OLake Go replicates the source into Apache Iceberg tables in a catalog the engine reads, so one copy of the data serves Snowflake, Databricks, BigQuery, DuckDB, Spark and Trino at the same time.

Pick the engine you query with:

- [Snowflake](/docs/integrations/snowflake/)
- [ClickHouse](/docs/integrations/clickhouse/)
- [DuckDB](/docs/integrations/duckdb/)
- [Amazon Redshift](/docs/integrations/redshift/)
- [Google BigQuery](/docs/integrations/bigquery/)
- [Databricks](/docs/integrations/databricks/)
- [Apache Iceberg](/docs/integrations/iceberg/), read by Spark, DuckDB and Trino

More engines: [Amazon Athena](/docs/integrations/athena/), [Trino](/docs/integrations/trino/), [Apache Spark](/docs/integrations/spark/), [Spark on Amazon EMR](/docs/integrations/emr/), [Google Cloud Dataproc](/docs/integrations/dataproc/), [Starburst](/docs/integrations/starburst/), [Presto](/docs/integrations/presto/), [Apache Doris](/docs/integrations/doris/), [StarRocks](/docs/integrations/starrocks/) and [Microsoft Fabric](/docs/integrations/fabric/).

Or start from the catalog: [AWS Glue](/docs/integrations/catalogs/glue/), [Apache Polaris](/docs/integrations/catalogs/polaris/), [Lakekeeper](/docs/integrations/catalogs/lakekeeper/), [Snowflake Horizon](/docs/integrations/catalogs/horizon/), [Unity Catalog](/docs/integrations/catalogs/unity/), [BigLake](/docs/integrations/catalogs/biglake/) and [Amazon S3 Tables](/docs/integrations/catalogs/s3tables/).

Every page states the catalogs it offers, which ones were tested, and which Iceberg delete format the engine can read. The full matrix is on the [query engine compatibility](/docs/understanding/compatibility-engines/) page.
