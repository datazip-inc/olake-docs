Apache Doris reads Iceberg tables through an Iceberg catalog. From release 4.1 it reads all three delete formats.

**Short answer.** To query replicated data in Doris, run OLake Go with AWS Glue, Polaris, Lakekeeper, Amazon S3 Tables or Hive Metastore as the Iceberg catalog, and create an Iceberg catalog in Doris for it. Doris 3.x and 4.0 read positional and equality deletes. Deletion vectors need Doris 4.1.0 or later.

_Last reviewed October 2026._

## How OLake Go gets data into Apache Doris

OLake Go uses change data capture (CDC) where the source has it. It commits Iceberg tables to the catalog. Doris reads [Polaris](/docs/integrations/catalogs/polaris/) over REST (representational state transfer), [Lakekeeper](/docs/integrations/catalogs/lakekeeper/) with vended credentials, and S3 Tables over REST with request signing.

No guide ends in Doris yet. The [Doris lakehouse post](/blog/postgres-iceberg-doris-lakehouse-olake/) shows an earlier Postgres setup.

## When to use it

- You run Doris for analytics and want replicated tables beside its internal tables.
- The tables use deletion vectors and Doris is on 4.1 or later.

## When not to use it

- You run Doris before 4.1 and the tables use deletion vectors.
- You plan a JDBC catalog for production. Doris marks its JDBC catalog experimental.
