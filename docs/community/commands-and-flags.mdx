# OLake Go Commands and Flags

import StreamsFormatNotice from '@site/docs/shared/streams/StreamsFormatNotice.mdx';

<StreamsFormatNotice />

OLake Go provides a set of CLI commands, each designed for specific use cases.


**Commands can be executed in three ways:**
- Using the `build.sh` script
- Running the generated binary
- Through the [OLake Go Docker CLI](/docs/install/docker-cli).

```bash title="build.sh command"
./build.sh driver-[SOURCE-TYPE] [COMMAND] [FLAG]
```
:::warning[Compatibility]
The `./build.sh` script is a Unix shell script. It runs natively on Linux and macOS terminals.

For Windows:
- Use Git Bash, WSL (Windows Subsystem for Linux), or another Unix-like shell.
- Alternatively, use the OLake Go Docker CLI, which works consistently across platforms.
:::

**Explanation of placeholders:**
- **SOURCE-TYPE** → The source driver being used.
- **COMMAND** → The action to perform (listed in the sections below).
- **FLAG** → Additional configuration for fine-tuning the command.

:::info[Using the binary]
Executing build.sh creates a binary file in the configuration directory.

Once available, the binary can be called directly to run commands, without needing build.sh.
:::

## Commands

### 1. Check

```bash
./build.sh driver-[SOURCE-TYPE] check [FLAG]
```
#### Description:
Verifies the connection to either a source or a destination. For source connectors that support CDC, the check also evaluates CDC prerequisites: 
- Required checks must pass for a successful test connection.
- Optional checks are not required. They show recommended values for good to have settings. You can fix those settings or continue without changing them.

#### Required flags:
Only one among these is required:
- [**`--config`**](/docs/community/commands-and-flags#2-config) → Checks the connection to a source.
- [**`--destination`**](/docs/community/commands-and-flags#5-destination) → Checks the connection to a destination.


### 2. Spec
```bash
./build.sh driver-[SOURCE-TYPE] spec [FLAG]
```
#### Description:
Generates a JSON Schema and UI Schema. These schemas are used by [RJSF](https://rjsf-team.github.io/react-jsonschema-form/docs/) to render and validate configuration forms.

When no flag is provided, the spec of the defined `SOURCE-TYPE` is generated.

#### Optional flags:
- [**`--destination-type`**](/docs/community/commands-and-flags#8-destination-type) → Generates the spec for a destination driver instead of the source.<br/>
- [**`--available-query-engines`**](/docs/community/commands-and-flags#17-available-query-engines) → Lists the query engines OLake Go supports. Use these names as input for [`--target-query-engines`](/docs/community/commands-and-flags#16-target-query-engines) while running **Discover** command.

### 3. Discover
```bash
./build.sh driver-[SOURCE-TYPE] discover [FLAG]
```
#### Description:
Writes `selected_streams.json`, `available_streams.json` and the legacy `streams.json` file containing information about all streams in the source.

#### Required flags:
- [**`--config`**](/docs/community/commands-and-flags#2-config) → Specifies path to the source configuration file. Not needed for `--difference-*` runs.

#### Optional flags:
- [**`--selected-streams`**](/docs/community/commands-and-flags#4-selected-streams) + [**`--available-streams`**](/docs/community/commands-and-flags#3-available-streams) → Re-run discover with both flags so `available_streams` reflects all tables with updated schema at the source, and `selected_streams` keeps the tables you already chose and your edits, including schema updates for those streams.
- [**`--difference-selected-streams`**](/docs/community/commands-and-flags#15-difference-selected-streams) + [**`--difference-available-streams`**](/docs/community/commands-and-flags#14-difference-available-streams) → Pass both flags to compare current and updated stream files and writes `difference_available_streams.json` and `difference_selected_streams.json`.
- [**`--destination-database-prefix`**](/docs/community/commands-and-flags#7-destination-database-prefix) → Adds a custom prefix to the destination database name.
- [**`--timeout`**](/docs/community/commands-and-flags#11-timeout) → Overrides the default timeout value for the command.
- [**`--max-discover-threads`**](/docs/community/commands-and-flags#12-max-discover-threads) → Max number of parallel threads for discovery of table in database.
- [**`--target-query-engines`**](/docs/community/commands-and-flags#16-target-query-engines) → Comma-separated query engines (for example `trino,databricks,spark`) so discover lists only delete formats all of these engines support in `available_streams.json` and the `selected_streams.json` will include the higher priority delete format supported by all the engines.

### 4. Sync
```bash
./build.sh driver-[SOURCE-TYPE] sync [FLAG]
```
#### Description:
Used to sync the data from the source to the destination.

#### Required flags:
All of these flags need to be specified:
- [**`--config`**](/docs/community/commands-and-flags#2-config) → Specifies path to the source configuration file.
- [**`--selected-streams`**](/docs/community/commands-and-flags#4-selected-streams) + [**`--available-streams`**](/docs/community/commands-and-flags#3-available-streams) → Specify paths to `selected_streams.json` and `available_streams.json` (produced by the discover command). 
- [**`--destination`**](/docs/community/commands-and-flags#5-destination) → Specifies path to the destination configuration file.

#### Optional flags:
- [**`--state`**](/docs/community/commands-and-flags#6-state) → Specifies path to the state file.
- [**`--discover-schema`**](/docs/community/commands-and-flags#13-discover-schema) → Enables source schema discovery during sync.

:::info
➡️ You must learn about `stats.json` configuration. Refer to the [Stats Config](/docs/install/docker-cli#stats) guide.
:::

### 5. Clear Destination
```bash
./build.sh driver-[SOURCE-TYPE] clear-destination [FLAG]
``` 
#### Description:
- Clears data in the destination, only for the streams listed in `selected_streams.json` (or in legacy `streams.json`).

#### Required flags:
All of these flags need to be specified:
- [**`--selected-streams`**](/docs/community/commands-and-flags#4-selected-streams) + [**`--available-streams`**](/docs/community/commands-and-flags#3-available-streams) → Specify paths to `selected_streams.json` and `available_streams.json` (produced by the discover command). 
- [**`--destination`**](/docs/community/commands-and-flags#5-destination) → Specifies path to the destination configuration file.

#### Optional flags:
- [**`--state`**](/docs/community/commands-and-flags#6-state) → Used to reset the state file for selected streams.
