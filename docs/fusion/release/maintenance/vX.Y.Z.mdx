# OLake Fusion (&lt;version&gt;)
&lt;release dates&gt;

## 🎯 What's New

### Platform Features

1. **S3 log file storage for Fusion -** <br/> Fusion now supports S3 log file storage mode (`global.logFileStorageMode: s3`) in the Helm chart. Logs of compaction and snapshot expiry runs are uploaded to the `s3LogFileStorage` bucket when the run completes, and the OLake UI reads them from S3. Fusion no longer requires an NFS/RWX shared volume in S3 mode. See [S3 Log File Storage Configuration](/docs/fusion/install/kubernetes-compaction/#s3-log-file-storage-configuration).
