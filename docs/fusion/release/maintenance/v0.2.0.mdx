# OLake Fusion (v0.2.0)
Aug 26, 2026 – Oct 21, 2026

## 🎯 What's New

### Catalogs

1. **Test catalog connection before creation -** <br/> Added a catalog connection test API that will validate catalog credentials/configuration before creating the catalog.

### Platform Features

1. **Added Usage Telemetry -** <br/> Added telemetry tracking for platform information, compaction start and completion events, and catalog additions.

2. **Added Kubernetes-Managed Optimizer -** <br/> Added support for running and managing the optimizer through Kubernetes.

3. **Added Catalog Creation Failure Telemetry -** <br/> Fusion event to report catalog creation failures with error classifications, without exposing sensitive connection details.

## 🔧 Bug Fixes & Stability

1. **Fixed Prometheus Exporter Startup Failure -** <br/> Packaged the Prometheus reporter JAR in the release assembly to prevent AMS startup failures when the Prometheus exporter is enabled.

2. **Fixed Lite Optimization Skipping -** <br/> Updated optimization checks to allow Lite optimization to proceed when at least one equality delete file exists and the minor optimization cron is triggered.

3. **Fixed Table Planning Failure Reporting -** <br/> Tables that fail during planning are now marked as failed in the UI, and the corresponding AMS error logs are included in the driver logs.

4. **Fixed Partition Compaction Planning -** <br/> Updated the planner to include all partitions of an Iceberg table in a single compaction planning run, preventing partitions from being left out.

5. **Fixed Fusion Release Workflow -** <br/> Updated the release workflow to support manually triggering container image builds.

6. **Added Fusion Integration Tests -** <br/> Added integration tests covering lite, medium, and full optimization, health score evaluation, skipped optimizations, and overall stack readiness.
