# OLake Fusion (v0.2.1)
Oct 22, 2026 – Nov 11, 2026

:::info[Version requirement]
Cleanup (snapshot expiry) needs **OLake UI v0.9.2 or later**. That release adds the **Cleanup** tab, the Run History type filter and the cleanup logs.
:::

## 🎯 What's New

### Table Maintenance

1. **Added Scheduled Snapshot Expiry (Cleanup) -** <br/> Fusion now expires the old snapshots of an Iceberg table when that table's cleanup cron fires (`snapshot-expire.enabled`, `snapshot-expire.trigger.cron`). For setup, see [Cleanup](/docs/fusion/cleanup/configuration/).
    - A run removes snapshots older than `snapshot.keep.duration` (default `7d`) and always keeps the newest `snapshot.keep.min-count` snapshots (default 30).
    - Expiry only trims the table's snapshot history. It deletes no data, delete or manifest files.
    - Each run makes up to 3 attempts and is recorded with its own status and logs.

## 🔧 Bug Fixes & Stability

1. **Removed Apache Derby and the Swagger UI Page -** <br/> Removed the Apache Derby dependency, which had a known vulnerability, and moved Fusion's own tests to PostgreSQL. OLake installs keep Fusion's metadata in PostgreSQL, so they are not affected. The Swagger UI page of the Fusion web UI (`/#/openapi-ui`) was removed with its vulnerable packages, and the OpenAPI specification is still served at `/swagger-docs`.

2. **Fixed Backend and Frontend Vulnerabilities -** <br/> Upgraded backend and frontend dependencies to fix high and moderate severity vulnerabilities.

3. **Fixed Frontend Build -** <br/> Fixed the frontend build of the release.

4. **Turned Off Telemetry in Integration Tests -** <br/> The integration tests now run OLake Go with `TELEMETRY_DISABLED=true`, so test runs no longer send usage events.
