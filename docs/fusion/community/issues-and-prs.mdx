# How to Raise a PR

1. Search the [OLake Fusion issues](https://github.com/datazip-inc/olake-fusion/issues) first, and open a new issue if none covers your change.
2. Fork [datazip-inc/olake-fusion](https://github.com/datazip-inc/olake-fusion), make the change on a branch, and open a pull request against the `staging` branch. Use a Conventional Commits title, such as `fix(ams): ...`, and link the issue.
3. Attach a short demo video of the change running, and follow the build, test and formatting rules in [CONTRIBUTING.md](https://github.com/datazip-inc/olake-fusion/blob/master/CONTRIBUTING.md).

## Goodies

OLake sends goodies, such as a T-shirt and stickers, for merged pull requests that add value. Typo and documentation fixes do not qualify. For the full conditions, see [Goodies](/docs/community/contributing/#goodies) in the OLake Go contributing guide.
