# Contributing

Contributions to OLake Fusion of all sizes are welcome. The contribution guide lives in the repository, in [CONTRIBUTING.md](https://github.com/datazip-inc/olake-fusion/blob/master/CONTRIBUTING.md). It covers how to build and test locally, IDE setup, debug mode, formatting rules and pull request requirements.

To discuss a change before you start, join [Slack](https://olake.io/slack/) or open a [GitHub issue](https://github.com/datazip-inc/olake-fusion/issues). To raise a pull request, see [How to Raise a PR](/docs/fusion/community/issues-and-prs/).
